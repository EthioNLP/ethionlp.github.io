Contributing a photograph

Upload the photograph through the form. GitHub takes the upload, and a workflow copies the image into the repository, writes the gallery entry and opens it for review. No Git knowledge is required, and the image is stored in the repository rather than linked from elsewhere.

{% include icon.html name="plus" %} Upload a photograph

If you would rather do it by hand, add the image to resources/img/gallery/ and append an entry to _data/gallery.yml. Only src and caption are required. Use plain ASCII filenames.

Write a caption that says what is happening, not just where. Name only people who are happy to be named; leave people out if you are not sure.

No GitHub account? Mail the photographs to {{ site.email }} with a sentence about each.
