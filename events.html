Putting an event on this page

By form, or by adding the file yourself.

  1. Event submission form

    The issue form asks for a title, a date, a kind and a one-line summary. A workflow turns your answers into the right file and opens a pull request; a maintainer merges it and the event is live.

    Open the form

  2. Adding the file yourself

    Copy _events/EXAMPLE-community-seminar.md, rename it to _events/YYYY-MM-DD-your-slug.md, delete the published: false line and fill in the fields. Every field is documented in that file. Only title, kind and start are required.

    {% include icon.html name="github" %} See the template

  3. Cancelling or changing an event

    Edit the file. Set status: cancelled to keep it on the record with a strike through it, or delete the file to remove it entirely. Changing the date is changing one line, nothing else references it.
